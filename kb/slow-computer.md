# Computer Running Slow or Freezing

## Symptoms
- Programs take a long time to open or show "Not Responding"
- The fan is loud and the computer feels hot
- The computer freezes and needs a forced restart

## Troubleshooting Steps
1. Restart the computer (Start > Power > Restart, not just closing the lid). Many slowdowns are caused by machines that haven't been restarted in weeks.
2. Open Task Manager (Ctrl+Shift+Esc), sort by CPU, Memory, and Disk, and close programs using a lot of resources that you don't need.
3. Close unused browser tabs and disable unneeded browser extensions.
4. Check free disk space in File Explorer > This PC. If the C: drive is nearly full, empty the Recycle Bin and run Settings > System > Storage > Cleanup recommendations.
5. Disable unnecessary startup apps: Task Manager > Startup apps, and disable anything you don't need at login.
6. Install pending updates: Settings > Windows Update > Check for updates, then restart.
7. Run a quick scan with Windows Security (Virus & threat protection > Quick scan) to rule out malware.

## When to Escalate
- The computer is still slow after cleanup and updates, or makes clicking noises (possible failing drive).
- Malware is detected and can't be removed.

## Recommended Next Action
Technician to check disk health (SMART), RAM usage and capacity, and malware; consider an SSD/RAM upgrade or reimaging the device.
