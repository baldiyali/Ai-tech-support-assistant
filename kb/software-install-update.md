# Software Won't Install, Open or Update

## Symptoms
- An application won't open, crashes, or shows an error
- Installation fails or asks for administrator rights
- "Unlicensed product" or activation messages

## Troubleshooting Steps
1. Note the exact error message (take a screenshot with Win+Shift+S).
2. Close the application completely (check Task Manager), then reopen it.
3. Restart your computer, then try again. Pending updates often block installs.
4. Install pending updates for Windows (Settings > Windows Update) and for the app itself.
5. For Microsoft 365 apps, sign out and back in under File > Account to refresh the license.
6. Repair the app: Settings > Apps > Installed apps > select the app > Advanced options/Modify > Repair.
7. Uninstall and reinstall the application from the company software portal or the official vendor site.

## When to Escalate
- The installation requires administrator rights you don't have.
- The software needs a new or additional license.

## Recommended Next Action
Install or repair the software with admin rights, assign the needed license, and confirm the app is on the approved software list.
