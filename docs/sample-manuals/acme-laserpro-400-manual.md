# Acme LaserPro 400 Office Printer - Troubleshooting Manual

> Sample vendor manual (fictional) used to demo document upload + retrieval.

## Error Codes

### E-13 Paper Jam in Tray 2
Open the right-side door and pull the green lever down. Remove the jammed sheet slowly with both hands. Fan the paper stack before reloading Tray 2 and never fill it above the max-fill line.

### E-49 Fuser Communication Error
Turn the printer off and wait 60 seconds. Remove any USB drive from the front port, then power on. If E-49 returns, the fuser unit must be replaced by an authorized technician; do not open the rear cover, the fuser is hot.

### E-81 Toner Cartridge Not Recognised
Remove the toner cartridge, rock it gently side to side five times, remove the orange shipping tab if present, and reinsert it until it clicks.

## Network Setup
The LaserPro 400 gets its IP address by DHCP. Print a configuration page by holding the Cancel button for 5 seconds; the IP address is listed under "Network Status". If the IP starts with 169.254 the printer can't reach the router: check the Ethernet cable and switch port.

## Faded or Streaky Prints
Run the cleaning page from Settings > Maintenance > Clean Drum. Replace the toner when the panel shows "Toner Low" and prints are faded.
